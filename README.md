# Chilli Community: second brain

Chilli Community is the worked example in the CoEngineers programme: a chilli-only membership for UK beginners called Windowsill to Plate. This is its second brain, the place where everything it knows is kept. Its real-world results (conversations, tests, asks and the pilot) are simulated for the course.

Each week's work was saved by one change. Read the pages in `weekly/` in order, from Week 0 to Week 26 (there is no Week 1).

Folders: `weekly` (one page per week), `business`, `customers`, `offer`, `product`, `growth`, `brand`, `sources` (where each line came from) and `simulated` (the made-up results, one file per week).

Chilli's app: https://app.chilli.coengineers.ai (use the demo login on the page).
